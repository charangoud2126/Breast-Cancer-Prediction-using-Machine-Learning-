# 🫁Breast Cancer Classification using Machine Learning

This project is part of my 50 Days, 50 Projects journey to strengthen my Data Science and Machine Learning skills for placements.

In this project, I built a Breast Cancer Classification model to predict whether a tumor is malignant (cancerous) or benign (non-cancerous) using supervised machine learning techniques. Early detection of breast cancer can significantly improve treatment outcomes, making this classification task highly impactful.

## Project Objective

The main goal of this project is to:

Perform data preprocessing and exploratory analysis

Build a classification model using Logistic Regression

Evaluate model performance using accuracy metrics

Understand how feature patterns influence cancer diagnosis

## Dataset Information

The dataset is taken from Scikit-learn Breast Cancer Wisconsin dataset, which contains:

569 samples

30 numerical features describing tumor characteristics

Target labels:

### 0 → Malignant

### 1 → Benign

### Key features include:

Mean radius

Texture

Perimeter

Area

Smoothness

Compactness

Concavity
